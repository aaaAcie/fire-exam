# 消防设施操作员（中级）理论模拟考试

纯静态网站，固定内置 200 道题目，支持账号密码登录、全部题目连续滚动、分类答题卡、统一交卷与成绩复核、刷新恢复进度。

## 使用

1. 将本文件夹内的 **index.html、style.css、app.js、questions.js** 四个文件全部上传到 GitHub 仓库根目录。
2. 进入仓库 `Settings → Pages → Build and deployment`，Source 选择 `Deploy from a branch`，Branch 选 `main`，Folder 选 `/(root)`，点击 Save。
3. 等待 GitHub Pages 发布，打开显示的网站地址。

可直接双击 index.html 本地使用（题库通过 questions.js 静态加载，不需要服务器）。

## 默认账号与密码

- 账号：`admin`
- 密码：`123456`

修改账号密码：打开 `app.js`，找到 `const CREDENTIALS` 并修改。

> **安全限制**：这是纯前端模拟登录。所有访问者都可以通过浏览器开发者工具查看前端代码、登录账号和标准答案。因此仅适合公开/内部练习，不应作为真正的身份验证或保密考试系统。公开 GitHub 仓库里的题库也是公开的。

## 题库

题库已从《消防设施操作员中级理论题库.xlsx》原样转换为 `questions.js`，包含单选 100 题、多选 40 题、判断 60 题。每题 0.5 分，满分 100 分，60 分合格；多选少选、错选均不得分。部分题目没有解析，则只显示标准答案。

## 进度

答题进度保存于当前浏览器的 localStorage；多个用户在同一台设备及浏览器上会共用这一份进度。通过“重新考试”可清除原答题记录。登录状态保存于 sessionStorage，关闭标签页后可能需要重新登录。

本项目为非官方模拟考试页面，不隶属于消防行业职业技能鉴定机构。
